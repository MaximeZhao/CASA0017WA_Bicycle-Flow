Total: 19,094 observations and 24 capture times. The CSV timestamps have no zone suffix. This import explicitly uses UTC, equal to London local time on 4–5 November 2026.

795 stations have 24 records. BikePoints_258 (Kensington Gore) and BikePoints_373 (Prince Consort Road) have only the first seven records, ending 4 November 20:06:03. Missing observations are not zero. Capacity changes and closed/zero-capacity observations are retained as recorded.

All 797 stations are used; the V4 400-station selection does not apply. V5 keeps its existing 2,288 regional historical collisions, whose coverage is narrower than the new full station network.

Playback uses only real recorded timestamps. Calendar dates remain separate. Fifteen-minute freshness is retained. Standard bikes, electric bikes and unavailable docks are stored in each history record. Reported faults remain unknown.

Later imports append by default. Duplicate station/timestamp values are skipped only when their values match. Invalid rows and conflicts reject the import before the active dataset is changed. Local backups and source CSV copies make imports reviewable and recoverable.
